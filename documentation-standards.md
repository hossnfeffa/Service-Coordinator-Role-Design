# Documentation Standards

The conventions applied across every document in the set.

---

## Standard section order

1. **Purpose:** why the document exists, in one or two sentences
2. **Scope:** who and what it applies to, and what it does not cover
3. **Resources:** related documents, tools, and prerequisites
4. **Process:** the procedure itself
5. **Ownership:** owner, approver, effective date
6. **Revision History:** version, date, author, summary of changes

Every document carries a classification marking (for example, *Internal Use Only*) at the top.

## Formatting conventions

| Element | Convention | Why |
| --- | --- | --- |
| Sequential steps | Numbered lists | Order matters and steps can be referenced ("see step 4") |
| Non-sequential points | Arrow bullets (→) | Visually distinct from steps |
| Warnings | Shaded callout box | Hard to miss; placed at the point of risk |
| Tips | Shaded callout box, different color | Helpful but optional |
| Notes / examples | Gray quoted block | Separates context from instruction |
| Decision points | Tables or flowcharts | Faster to scan than paragraphs |

## Writing principles

- **Write for the newest person on the team.** If a step needs tribal knowledge, write that knowledge down.
- **One instruction per step.**
- **Use active voice and imperative mood.** "Assign the ticket to…", not "The ticket should be assigned…"
- **Use the canonical term every time.** No synonyms for roles, tiers, or priorities.
- **Match the format to the moment.** Use full SOPs for learning and quick references for doing.

## Versioning

| Change type | Version bump | Example |
| --- | --- | --- |
| Typo or formatting fix | None (note in history) | 1.0 → 1.0 |
| Content update, same process | Minor | 1.0 → 1.1 |
| Process change or restructure | Major | 1.1 → 2.0 |

## Document types

| Type | Length | Audience | Use case |
| --- | --- | --- | --- |
| **SOP** | Multi-page | All staff, trainers | Reference and training |
| **Workflow** | 1–2 pages | Experienced staff | Fast decision path |
| **Quick Reference** | 1 page | Staff under time pressure | Live incidents, phone calls |
| **Standard** | 1–3 pages | All staff | Defines "what good looks like" |
| **Matrix** | Table | Staff, managers | Roles, skills, career planning |
| **Training Program** | Multi-week plan | New hires, trainers | Structured onboarding |
