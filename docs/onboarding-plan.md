# Service Coordinator Onboarding Plan

New Service Coordinators ramp up in three phases. Each phase has concrete focus areas and **measurable success criteria**, so the coordinator and their supervisor both know when it is time to move on.

```mermaid
flowchart LR
    A[Foundation<br/>Weeks 1–3] --> B[Integration<br/>Weeks 4–5] --> C[Autonomy<br/>Month 2+]
```

---

## Phase 1: Foundation (Weeks 1–3)

**Goal:** Learn the tools, the boards, and the escalation paths, then watch experienced people do the job.

| Focus | Success criteria |
|-------|------------------|
| Set up PSA, access-management, and reporting logins and security roles | Can log in and reach the relevant boards and views without issues |
| Complete PSA dispatcher training | Completes the training modules and passes an internal quiz or review |
| Ticket lifecycle & SLA walkthrough | Can describe each ticket stage and its SLA impact |
| PSA calendar training | Can use the calendar to manage scheduling |
| Review service boards and escalation paths | Can clearly explain the escalation paths and what each board is for |
| Shadow L1 technicians, then L2 technicians, then the Service Desk Supervisor | Has observed dispatch decisions, escalations, and the hand-off to Systems Engineers firsthand |
| Passive dispatching alongside an experienced dispatcher | Comfortable with email ticket dispatch and phone call flow |

## Phase 2: Integration (Weeks 4–5)

**Goal:** Dispatch actively, own the calendar, and start reporting on the numbers.

| Focus | Success criteria |
|-------|------------------|
| Complete reporting-platform training | Can use the dashboard tools and edit content |
| Begin active dispatching, assigning tickets by skill set and SLA priority | **90%** of tickets assigned within the SLA window and matched to the right technician |
| Use the SLA dashboard and calendar to manage workload | Uses the calendar daily and flags conflicts or overloads proactively |
| Learn escalation rules and notification settings | Routes escalations correctly about **95%** of the time |
| Monitor and share weekly KPIs: response time, resolution time, SLA breaches, technician utilization | Generates a weekly KPI report and reviews it with the service manager |

## Phase 3: Autonomy (Month 2+)

→ Works independently against the standards in the [SOP](service-coordinator-sop.md).

→ Helps refine the onboarding materials for the next new Service Coordinator.
